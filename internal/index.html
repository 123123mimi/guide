02.

콘텐츠 코드 관리 규칙

콘텐츠는 FTP 서버와 LMS 코드 번호를 일치시켜 관리합니다.
단, CC 과정은 기존 등록된 콘텐츠를 재등록하지 않고 조합하여 사용합니다.

콘텐츠 코드 분류
PC0000 — 비환급과정 (차시별, 최초 등록 콘텐츠)
HC0000 — 환급과정 (콘텐츠별 별도 관리)
SC0000 — 경비 콘텐츠
CC0000 — 커스텀 콘텐츠
MD0000 — 산업안전 콘텐츠

[콘텐츠 교·강사 관리]

심사

e-심사 콘텐츠 등록 및 과정 심사

01.

콘텐츠 등록

01.

e-심사 개요

콘텐츠(영상)은 e-simsa에서 콘텐츠 등록 후 과정 심사를 거쳐 환급 과정으로 사용
로그인 계정: pocketclass_cp
등록 후 2주~한달 내 "적합/비적합" 확인

02.

기존 등록 콘텐츠 확인

기존 등록된 콘텐츠명을 클릭하여 진행했던 신청 내용 확인 가능

03.

콘텐츠 등록 신청 준비 자료

1. 콘텐츠(영상 - LMS 등록 및 개강까지)
2. 과정 개요서
3. 학습 시간
평가방법 및 콘텐츠 학습정보란에 엑셀(과정개요/시간값) 입력

04.

콘텐츠 등록 정보 확인

콘텐츠 등록 후 콘텐츠명 눌러 등록된 정보 확인 가능 / 엑셀 다운로드 가능

05.

사용기관 등록

환급 과정 이용/과정 임대 등 콘텐츠 사용 시 사용기관에 등록 필요
환급 과정 이용 시 행정팀을 통해 HRD 등록도 함께 진행

02.

과정 심사

06.

과정 심사 개요

콘텐츠 등록 후 "적합" 판정 뒤 과정 심사 진행 가능
계정: Pocketclass
과정 심사는 심사 일정이 별도로 있어 일정 확인 후 진행
사용할 콘텐츠는 과정 심사 한달 전에는 콘텐츠 등록을 꼭 먼저 진행

07.

과정심사 방법

1. Pocketclass > 로그인 시도 > 이메일 인증 후 로그인
2. 과정심사 > 등록하기

08.

과정심사 등록 상세

배점에 따라 등급 부여 (80점 이상 A등급)

09.

등록된 내용 확인 (1)

콘텐츠명 선택 > 상단 탭 눌러서 확인. 입력된 정보에 대해 보기만 가능

10.

등록된 내용 확인 (2) - 심사결과

과정심사 > 심사결과 탭에서 콘텐츠 선택

11.

등록된 내용 확인 (2) - 개요서 확인

과정개요서 > 메인에서 봤던 내용과 동일
콘텐츠개요서 > 등록한 파일 다운로드 가능

12.

환급과정 등록 및 관리

환급과정은 수강생 수료 후 기업/훈련생에게 환급금이 발생하는 과정이므로 HRD 등록이 필수입니다.
심사 통과(적합 판정) 후 약 일주일 뒤 [HRD-Net]에서 과정 검색이 연동/조회되면 등록 후 사용할 수 있습니다.
심사받은 콘텐츠는 유효기간이 있습니다.
기본 유효기간은 1년이며, 만료 전 연장 신청을 하면 재심사 없이 기존 승인 내용대로 1년 더 연장 사용 가능합니다.

※ 등록 시 오류를 막기 위해 입력 값은 행정팀과 함께 더블체크를 진행한 후 최종 확정합니다.

PPT 제작

원고 확인부터 PPT 제작까지

01.

원고 확인 및 PPT 진행

01.

강사 원고 확인

강사가 작성한 원고를 확인합니다.
분량 체크: 차시별 분량이 적절한지 확인
내용 확인: 학습 목표에 맞는 내용인지 검토
* 강사에 따라 원고 스타일이 다릅니다 (아래 이미지 참고)

02.

PPT 제작 순서

원고를 기반으로 아래 순서에 따라 PPT를 제작합니다.
1. 썸네일 (진행 표지)
2. 학습목차 + 학습내용
3. 섹션 구분
4. 본문 슬라이드

03.

이미지 활용

PPT 제작 시 이미지는 게티이미지뱅크를 활용합니다.
URL: https://www.gettyimagesbank.com/
이미지 소스, PPT 템플릿 등 이용 가능
* 26년 10월 16일까지 사용 가능 / 사용 연장은 류대표님과 상의 필요

04.

기존 과정 PPT 원본 확인

기존에 제작된 과정의 PPT 원본은 외장하드에서 확인할 수 있습니다.
경로: E(외장하드) > 999 콘텐츠팀 > 02 콘텐츠 > 과정명
* 02 콘텐츠 폴더에서 강사자료/교안/심사자료 등 모두 확인 가능

디자인

CI, 명함, 썸네일 등 디자인 자료

01.

디자인 자료 확인

01.

기타 디자인 자료

포켓클래스 CI, 명함, 썸네일 등 디자인 관련 자료는 외장하드에서 확인할 수 있습니다.
경로: E(외장하드) > 999 콘텐츠팀 > 01 디자인

노션

업무 요청 및 관리

01.

노션 (Notion) 사용 가이드

업무 요청 및 관리는 노션을 통해 진행합니다.
노션 아이디는 류대표님을 통해 공유받으시면 됩니다.
01.

공지사항 확인

노션 메인 페이지의 NOTICE 영역에서 공지사항을 확인합니다.
"전사공지"의 경우 전 사원 확인이 필요하므로, 내용을 확인한 후 "확인한사람"에 이름을 체크해주세요.

02.

TASK에서 업무 요청하기

TASK 공간에서 업무 요청이 진행됩니다.
각 팀별로 나눠져 있으며, 요청 시에는 [새로 만들기] → [부서 선택] → [요청사항 입력] 순서로 요청합니다.
담당자 지정과 @로 이름을 걸어 요청 업무를 확인할 수 있도록 전달합니다.

03.

요청받은 업무 처리

다른 팀에서 업무 요청을 할 경우, 리스트에서 확인 또는 알람을 확인하여 내용을 처리합니다.
처리 상황에 따라 상태를 변경하여 진행 사항을 공유합니다.

04.

팀별 관리 내용 확인

팀별로 관리되는 내용을 확인할 수 있습니다.
콘텐츠팀의 경우 "콘텐츠팀" 내용과 "공통업무" 내용을 확인해 주시면 됩니다.

05.

주간보고 등록

공통업무 중 [주간보고]는 금요일에 등록합니다.
월요일 주간회의에 해당 내용을 토대로 회의가 진행됩니다.
